📋 Setup Checklist

  • Install Node.js and npm
  • Run npm install in project directory
  • Login to Cloudflare: npx wrangler login
  • Create D1 database: npm run db:create
  • Update database ID in wrangler.jsonc
  • Run migrations: npm run db:migrate:remote
  • Set up PayPal Developer account
  • Set up EasyPost account
  • Configure all Wrangler secrets (see below)
  • Deploy Worker: npm run deploy
  • Update API URL in shop.html
  • Update PayPal Client ID in shop.html

🔑 Required Secrets

Run these commands and paste your credentials when prompted:

npx wrangler secret put PAYPAL_CLIENT_ID
npx wrangler secret put PAYPAL_CLIENT_SECRET
npx wrangler secret put PAYPAL_MODE
npx wrangler secret put EASYPOST_API_KEY
npx wrangler secret put SHIP_FROM_NAME
npx wrangler secret put SHIP_FROM_STREET1
npx wrangler secret put SHIP_FROM_CITY
npx wrangler secret put SHIP_FROM_STATE
npx wrangler secret put SHIP_FROM_ZIP
npx wrangler secret put SHIP_FROM_COUNTRY
npx wrangler secret put SHIP_FROM_PHONE

📝 Get Your Credentials

PayPal (for payments)

1. Go to PayPal Developer Dashboard
2. Create a new app or use existing
3. Copy your Client ID and Secret
4. Use "sandbox" mode for testing, "live" for production

EasyPost (for shipping)

1. Go to EasyPost Signup
2. Create a free account
3. Copy your API Key from the dashboard
4. Test mode is free, production charges only for actual labels

🧪 Local Development

To test locally before deploying:

# Start local development server
npm run dev

# Open shop.html in browser
# Make sure API_URL is set to: http://localhost:8787/api

🌐 Production Deployment

Once everything is configured:

# Deploy to Cloudflare
npm run deploy

# Update shop.html with your Worker URL
# const API_URL = 'https://falcon-drums-api.YOUR_SUBDOMAIN.workers.dev/api'
